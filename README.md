# CodeDiscussion API

CodeDiscussion is a scalable developer-focused Q&A platform built using ASP.NET Core Web API.

This backend handles authentication, question management, answer submission, voting, reputation tracking, and performance optimization.

---

## 🚀 Tech Stack

- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- JWT Authentication
- Redis (planned)
- Clean Architecture

---

## 🏗 Architecture

The project follows Clean Architecture principles:

CodeDiscussion.Api  
├── API (Controllers & Middleware)  
├── Application (Business Logic)  
├── Domain (Entities)  
└── Infrastructure (Database & Services)

---

## 🎯 Goals

This project demonstrates:

- Secure JWT-based authentication
- Role-based authorization
- Scalable relational database design
- Vote & reputation system implementation
- Pagination & optimized queries
- Clean separation of concerns
